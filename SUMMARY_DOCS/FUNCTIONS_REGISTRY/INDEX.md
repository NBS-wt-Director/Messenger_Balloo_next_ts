## 🔧 API Endpoints

### Публичные (без авторизации)

```
GET    /api/v1/functions              - Список функций (публичные)
GET    /api/v1/functions/:id          - Детали функции
GET    /api/v1/settings               - Публичные настройки
```

### Защищённые (требуется авторизация + Staff)

```
GET    /api/v1/functions/admin/all    - ВСЕ функции (включая скрытые)
POST   /api/v1/functions/admin/create - Создать функцию
PUT    /api/v1/functions/admin/update/:id - Обновить функцию
DELETE /api/v1/functions/admin/delete/:id - Удалить функцию (soft delete)
PUT    /api/v1/settings/update        - Обновить настройку
```
