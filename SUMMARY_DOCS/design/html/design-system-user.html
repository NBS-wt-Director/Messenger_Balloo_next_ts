📱 Mobile Responsive

Touch-friendly targets and responsive breakpoints

Touch Targets

Minimum 44px for all interactive elements on mobile

/* Mobile (≤640px) */
@media (max-width: 640px) {
  button, a, input {
    min-height: 44px;
    min-width: 44px;
  }
}
Breakpoints
  • Mobile: ≤640px (14px base font)
  • Tablet: 641px - 1024px (16px base font)
  • Desktop: ≥1024px (16px base font, 1200px container)
