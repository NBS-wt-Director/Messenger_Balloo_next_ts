## 🎯 ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 1. ThemeSelector

#### Состояния
- `isOpen` - открыто/закрыто модальное окно
- `activeTab` - текущая вкладка (presets / recent / favorites)
- `selectedTheme` - выбранная тема
- `loading` - загрузка данных
- `error` - ошибка

#### Методы
- `open()` - открыть модальное окно
- `close()` - закрыть модальное окно
- `selectTheme(theme)` - выбрать тему
- `loadThemes()` - загрузить темы с сервера
- `saveTheme(theme)` - сохранить пользовательскую тему

#### UI Структура
```
┌─────────────────────────────────────────┐
│  Выбор темы                      [X]    │
├─────────────────────────────────────────┤
│ [Предустановленные] [Последние] [Избран.]│
├─────────────────────────────────────────┤
│ ┌─────────┐ ┌─────────┐ ┌─────────┐    │
│ │  Темная  │ │  Светлая │ │ Россия  │    │
│ └─────────┘ └─────────┘ └─────────┘    │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐    │
│ │  Тема 1  │ │  Тема 2  │ │  Тема 3  │    │
│ └─────────┘ └─────────┘ └─────────┘    │
├─────────────────────────────────────────┤
│ [Сохранить как новую] [Создать тему]   │
└─────────────────────────────────────────┘
```

### 2. ThemeCard

#### Пропсы
- `theme: CustomTheme` - данные темы
- `selected: boolean` - выбрана ли тема
- `onSelect: () => void` - обработчик выбора
- `onFavorite: () => void` - добавление в избранное

#### UI Структура
```
┌──────────────┐
│   Превью     │
│   цвета      │
├──────────────┤
│   Название   │
│ [❤️] [Выбрать]│
└──────────────┘
```

### 3. ThemeSubscriptionDialog

#### Состояния
- `isOpen` - открыто/закрыто
- `days` - количество дней (1-30)
- `cost` - итоговая стоимость
- `loading` - процесс оплаты
- `error` - ошибка оплаты

#### Методы
- `open()` - открыть диалог
- `close()` - закрыть диалог
- `setDays(days)` - установить количество дней
- `activate()` - активировать подписку

#### UI Структура
```
┌─────────────────────────────────────────┐
│  Подписка на темы              [X]      │
├─────────────────────────────────────────┤
│ 3 балла в день                          │
│                                         │
│ Количество дней: [  7  ]                │
│                                         │
│ Итого: 21 балл                          │
│ Ваш баланс: 50 баллов                   │
│                                         │
│ [⚠️ Недостаточно средств]               │
│ [Активировать подписку]                 │
└─────────────────────────────────────────┘
```

## 🔌 API ENDPOINTS

### GET /api/v1/themes
```typescript
interface Response {
  success: boolean;
  data: {
    userThemes: CustomTheme[];
    recentThemes: CustomTheme[];
    favorites: CustomTheme[];
    subscription: {
      isActive: boolean;
      expiresAt?: number;
      daysLeft?: number;
    };
  };
}
```

### POST /api/v1/themes
```typescript
interface Request {
  name: string;
  colors: {
    primary: string;
    secondary: string;
    background: string;
    surface: string;
    text: string;
    textSecondary: string;
    border: string;
    accent: string;
  };
  isFavorite?: boolean;
}
```

### POST /api/v1/themes/subscriptions
```typescript
interface Request {
  days: number;
}

interface Response {
  success: boolean;
  data: {
    id: string;
    activatedAt: number;
    expiresAt: number;
    daysCount: number;
    cost: number;
  };
}
```

## 🧪 ТЕСТОВЫЕ СЦЕНАРИИ

### Сценарий 1: Авторизованный пользователь выбирает тему
1. Открыть модальное окно тем
2. Выбрать предустановленную тему
3. Проверить, что тема применена
4. Проверить, что тема добавлена в историю

### Сценарий 2: Пользователь создаёт тему
1. Открыть модальное окно тем
2. Нажать "Создать тему"
3. Ввести название и цвета
4. Сохранить
5. Проверить, что тема появилась в списке

### Сценарий 3: Активация подписки
1. Открыть модальное окно тем
2. Нажать на тему с замком 🔒
3. Выбрать количество дней
4. Проверить стоимость
5. Активировать подписку
6. Проверить, что списались баллы

### Сценарий 4: Недостаточно средств
1. Открыть модальное окно тем
2. Нажать на тему с замком 🔒
3. Выбрать количество дней
4. Проверить сообщение о недостатке средств
5. Перейти на страницу пополнения

### Сценарий 5: Неавторизованный пользователь
1. Открыть модальное окно тем
2. Посмотреть темы
3. Закрыть окно
4. Проверить, что тема сбросилась на светлую

---

## ⚠️ ОГРАНИЧЕНИЯ И ВАЖНЫЕ ПРИМЕЧАНИЯ

1. **Лимит избранных:** максимум 5 тем
2. **Лимит истории:** максимум 15 последних тем
3. **Стоимость подписки:** 3 балла в день
4. **Максимальная подписка:** 30 дней
5. **Анонимный режим:** тема сбрасывается после закрытия
