## 🎯 ТРЕБОВАНИЯ К КНОПКАМ

### Кнопка 1: Тёмная тема
- **Форма:** Прямоугольник
- **Иконка:** 🌙 (Moon)
- **Фон:** Тёмный цвет (#1a1a2e)
- **Текст:** "Тёмная"

### Кнопка 2: Светлая тема
- **Форма:** Прямоугольник
- **Иконка:** ☀️ (Sun)
- **Фон:** Светлый цвет (#f5f5f5)
- **Текст:** "Светлая"

### Кнопка 3: Россия тема
- **Форма:** Прямоугольник
- **Иконка:** 🇷🇺 (Flag)
- **Фон:** Градиент флага России (белый-синий-красный)
- **Текст:** "Россия"

### Кнопка 4: Все темы (новая)
- **Форма:** Прямоугольник
- **Иконка:** ? (вопросительный знак)
- **Фон:** Случайный цвет, меняется каждые 7 секунд
- **Текст:** "Все темы"
- **Особенность:** При наведении показывает текущий цвет
- **На теме Россия:** Фон = градиент флага России

## 🎨 ЦВЕТОВАЯ ЛОГИКА

### Случайный цвет для кнопки "?"
```javascript
// Генерация случайного цвета каждые 7 секунд
const randomColor = () => {
  const hue = Math.floor(Math.random() * 360);
  return `hsl(${hue}, 70%, 60%)`;
};

// Таймер
setInterval(() => {
  setRandomColor(randomColor());
}, 7000);
```

### Особый случай: тема "Россия"
Когда активна тема "Россия", кнопка "?" показывает:
- Градиент: белый → синий → красный
- Или чередование цветов флага

---

## 🔄 ЛОГИКА РАБОТЫ

1. **Пользователь нажимает на тему** → тема применяется
2. **Пользователь нажимает на "?"** → открывается модальное окно
3. **Модальное окно:**
   - Вкладка "Предустановленные" → 3 темы (тёмная, светлая, Россия)
   - Вкладка "Последние" → 15 последних тем (только для авторизованных)
   - Вкладка "Избранное" → 5 избранных тем (только для авторизованных)
4. **Неавторизованный:** при закрытии окна → сброс на светлую
