## 🚫 ЗАПРЕТ СКРУГЛЕНИЙ (CRITICAL!)

### ⚠️ ЯВНЫЙ ЗАПРЕТ
**border-radius НЕ ИСПОЛЬЗОВАТЬ ВООБЩЕ!**

```css
/* ❌ ЗАПРЕЩЕНО - ВСЕГДА! */
border-radius: 4px;
border-radius: 8px;
border-radius: 12px;
border-radius: 50%;
border-radius: 100%;
any border-radius value = NOT ALLOWED!

/* ✅ РАЗРЕШЕНО */
border-radius: 0;
/* Или просто не указывать */
```

### Почему?
- Скругления **ЛОМАЮТ** компонент
- Нарушается общая концепция дизайна
- Сломанный компонент = нерабочая функция
- **Никаких исключений!**

### Где проверять?
- Все компоненты UI
- Кнопки
- Инпуты
- Карточки
- Модальные окна
- Прямоугольники
- Всё!

## ⏰ ЛОГИКА СОХРАНЕНИЯ ТЕМЫ

### Алгоритм активации

```javascript
// Для авторизованных пользователей
const checkThemeActivation = async (themeId) => {
  const usage = await getThemeUsage(themeId);
  
  if (usage.days >= 2) {
    // Можно сохранить
    return { canSave: true };
  } else {
    // Нужно подождать
    const daysLeft = 2 - usage.days;
    return { 
      canSave: false,
      message: `Осталось дней: ${daysLeft}`,
      daysUsed: usage.days
    };
  }
};
```

### Таймер использования
```javascript
// При выборе темы
const startThemeUsageTimer = (themeId) => {
```

## 🔄 ЛОГИКА РАБОТЫ С ТЕМАМИ

### Сценарий 1: Неавторизованный пользователь
1. Открывает модальное окно тем
2. Выбирает любую тему (предустановленную или кастомную)
3. Тема применяется
4. Закрывает окно
5. **ТЕМА СБРАСЫВАЕТСЯ НА СВЕТЛУЮ**

### Сценарий 2: Авторизованный (меньше 2 дней)
1. Выбирает кастомную тему
2. Тема применяется
3. Видит индикатор: "Активация: 0 из 2 дней"
4. Кнопка "Сохранить" неактивна
5. Через 2 дня → кнопка становится активной

### Сценарий 3: Авторизованный (более 2 дней)
1. Выбирает кастомную тему
2. Тема применяется
3. Видит индикатор: "✅ Активация: 2 из 2 дней"
4. Кнопка "Сохранить" активна
5. Нажимает "Сохранить" → тема сохранена навсегда
