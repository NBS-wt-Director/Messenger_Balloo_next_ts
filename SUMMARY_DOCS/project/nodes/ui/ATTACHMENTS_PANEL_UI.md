# 🎨 ПАНЕЛЬ ВЛОЖЕНИЙ — УПРОЩЁННЫЙ UX

**Версия:** 2.0.0  
**Дата:** 2026-06-14  
**Автор:** NLP-Core-Team  
**Статус:** ✅ Complete

---

## 🎯 ЦЕЛЬ ПАНЕЛИ

**Назначение:** Быстрый и интуитивный выбор типа вложения для отправки в чат.

**Проблема предыдущей версии:**
- ❌ 26 вложений на одном уровне — визуально перегружено
- ❌ Пользователь не видит очевидного "быстрого пути"
- ❌ Premium-функции конкурируют с базовыми
- ❌ Категории описаны в терминах внутренней структуры, а не пользовательских сценариев

**Решение:** Progressive Disclosure (прогрессивное раскрытие)
- ✅ **Основной уровень** — 7 самых частых действий
- ✅ **Второй уровень "Ещё"** — редкие функции
- ✅ **Premium отдельно** — не конкурирует с базовыми

---

## 📐 ПРИНЦИПЫ УПРОЩЕНИЯ

### 1. Частотность использования

| Частота | Действия | Уровень |
|---------|----------|---------|
| **Ежедневно** | Фото, Видео, Файл, Голосовое | Основной |
| **Еженедельно** | Контакт, Локация, GIF, Стикеры | "Ещё" |
| **Ежемесячно** | Опрос, Список, Заметка, Событие | "Ещё" |
| **Редко** | Диаграмма, Музыка, Запись звонка | "Ещё" |
| **Premium** | Перевод, Игры, Исчезающие | Premium |

### 2. Пользовательские сценарии

```
┌─────────────────────────────────────────────────────────┐
│  СЦЕНАРИЙ: "Хочу поделиться фото с ужина"              │
│  → Основной уровень → Фото → Выбрать файл → Отправить  │
│  (3 клика, 5 секунд)                                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  СЦЕНАРИЙ: "Нужно отправить документ коллеге"          │
│  → Основной уровень → Файл → Выбрать файл → Отправить  │
│  (3 клика, 5 секунд)                                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  СЦЕНАРИЙ: "Хочу создать опрос в чате"                 │
│  → Основной → Ещё → Опрос → Создать → Отправить        │
│  (4 клика, 10 секунд) — приемлемо для редкого действия │
└─────────────────────────────────────────────────────────┘
```

### 3. Визуальная иерархия

```
Приоритет 1 (Основной): Крупные иконки, первый экран
Приоритет 2 (Ещё): Меньшие иконки, второй экран
Приоритет 3 (Premium): Отдельная секция, золотые маркеры
```

## 🖥️ DESKTOP ПОВЕДЕНИЕ

### Открытие панели:

**Триггер:** Клик на иконку 📎 справа от поля ввода

**Позиция:** Снизу вверх, привязка к полю ввода

**Размер:** 
- Ширина: 480px
- Максимальная высота: 600px
- Отступы: 16px

### Состояния:

| Состояние | Описание |
|-----------|----------|
| **Закрыто** | Видна только иконка 📎 |
| **Открыто (Уровень 1)** | 7 элементов основного уровня |
| **Открыто (Уровень 2)** | 14 элементов "Ещё" + кнопка "Назад" |
| **Premium (Шейх)** | 5 premium элементов внизу |
| **Premium (Free)** | 5 заблокированных элементов + CTA |

### Навигация:

```
[📎] → Открыть панель (Уровень 1)
         ↓
    [📂 Ещё] → Уровень 2
         ↓
      [🔙] → Уровень 1
         ↓
       [✕] → Закрыть
```

## 🔧 ПОВЕДЕНЧЕСКИЕ ПРАВИЛА

### Правило 1: Частотность определяет позицию

```
ЕСЛИ действие используется ежедневно → Основной уровень
ЕСЛИ действие используется еженедельно → Уровень "Ещё"
ЕСЛИ действие используется ежемесячно → Уровень "Ещё"
ЕСЛИ действие требует премиум-доступа → Premium секция
```

### Правило 2: Прогрессивное раскрытие

```
1. Показать только основное (7 элементов)
2. Если нужно больше → клик "Ещё"
3. Premium → всегда отдельно, не смешивать с бесплатными
```

### Правило 3: Визуальная иерархия

```
Основной уровень:
  - Размер: 100px (Desktop), 70px (Mobile)
  - Позиция: Первый экран
  - Приоритет: Максимальный

Уровень "Ещё":
  - Размер: 80px (Desktop), 60px (Mobile)
  - Позиция: Второй экран
  - Приоритет: Средний

Premium:
  - Размер: 80px (Desktop), 60px (Mobile)
  - Позиция: Отдельная секция внизу
  - Приоритет: Не конкурирует с основным
```

### Правило 4: Premium не должен мешать

```
ЕСЛИ пользователь Free → Premium показан с замком 🔒 + CTA "Оформить"
ЕСЛИ пользователь Шейх → Premium показан с короной 👑 + доступ разрешён
НИКОГДА не смешивать Premium с Основным уровнем
```

### Правило 5: Мобильная компактность

```
Mobile:
  - Максимум 3 колонки
  - Максимум 7 элементов на экране
  - Bottom sheet не более 70% высоты
  - Swipe down закрывает панель
```
