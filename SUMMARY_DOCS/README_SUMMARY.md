## 🚀 Быстрый старт

```bash

# Установить зависимости (если ещё не установлены)

# Запустить сайт разработки
npm run dev

```

## ✏️ Редактирование

### Через веб-редактор
1. Откройте http://localhost:3100/editor
2. Выберите файл из списка
3. Отредактируйте содержимое
4. Нажмите "Сохранить"

### Через файловую систему
1. Откройте файл в редакторе кода
2. Отредактируйте содержимое
3. Сохраните файл
4. Сайт обновится автоматически
