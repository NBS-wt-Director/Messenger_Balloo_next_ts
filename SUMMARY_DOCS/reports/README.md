## 🎯 НАЗНАЧЕНИЕ

Эта директория содержит **отчётную документацию** — фактическое состояние проекта Balloo.

**Здесь нельзя:**
- ❌ Писать "почти готово" без подтверждения сборкой
- ❌ Указывать проценты без проверки тестами
- ❌ Скрывать блокеры и проблемы
- ❌ Выдавать планы за факты
- ❌ Менять статус без фактического выполнения

**Здесь можно:**
- ✅ Описывать только проверенные факты
- ✅ Указывать реальные метрики (с обоснованием)
- ✅ Фиксировать проблемы и блокеры
- ✅ Отмечать расхождения с проектной документацией

## 🏷️ СИСТЕМА МАРКИРОВКИ

### Статусы честности

| Маркер | Значение | Доверять |
|--------|----------|----------|
| ✅ **Verified** | Проверено сборкой/тестами | Да, полностью |
| 🟡 **Unverified** | Не проверено, требует подтверждения | С осторожностью |
| 🔴 **Inflated** | Завышенные цифры, не доверять | Нет |
| ⚠️ **Mixed** | Смесь фактов и оценок | Частично |

### Статусы готовности

| Статус | Значение |
|--------|----------|
| 🔴 **Not Started** | Не начато |
| 🟡 **In Progress** | В работе |
| 🟠 **Partially Done** | Частично готово (50-79%) |
| 🟢 **Complete** | Полностью готово (80%+) |
| ✅ **Verified** | Проверено тестами |

## ✅ КРИТЕРИИ ПРОВЕРКИ ФАКТОВ

### Для статуса "Собрано":

- [ ] `npm run build` проходит без ошибок
- [ ] `docker-compose build` проходит без ошибок
- [ ] Артефакты сборки существуют

### Для статуса "Работает":

- [ ] Сервис запускается
- [ ] Health check проходит
- [ ] API endpoints отвечают

### Для статуса "Протестировано":

- [ ] Тесты написаны
- [ ] Тесты запускаются
- [ ] Coverage измерено
- [ ] Тесты в CI

### Для процента готовности:

- [ ] Есть чек-лист критериев
- [ ] Каждый пункт проверен
- [ ] Процент = (выполнено / всего) × 100%
- [ ] Округление до 5%

## 🚫 ЗАПРЕЩЕННЫЕ ПРИЁМЫ

**В отчётной документации НЕЛЬЗЯ использовать:**

| Фраза | Почему нельзя | Чем заменить |
|-------|---------------|--------------|
| "Почти готово" | Неизмеримо | "85% (17/20 критериев)" |
| "В целом работает" | Неясно что именно | "Работает X, не работает Y" |
| "90% complete" | Без обоснования | "90% (чек-лист в приложении)" |
| "Production-ready" | Без тестов | "Ready для staging (тесты: 60%)" |
| "Fully implemented" | Без проверки | "Implemented, verified: ✅/❌" |
