## 🚨 КРИТИЧЕСКИЕ ОШИБКИ (требуют исправления)

### 1. api/tsconfig.json
**Ошибка:** Отсутствует esModuleInterop  
**Файл:** `api/tsconfig.json`  
**Решение:** Добавить `"esModuleInterop": true`

### 2. messenger/tsconfig.json
**Ошибка:** Не может найти @balloo/tsconfig/next.json  
**Файл:** `messenger/tsconfig.json`  
**Решение:** Изменить extends на относительный путь

### 3. admin-portal/tsconfig.json
**Ошибка:** Не может найти @balloo/tsconfig/next.json  
**Файл:** `admin-portal/tsconfig.json`  
**Решение:** Изменить extends на относительный путь

### 4. api/src/index.ts
**Ошибка:** Неправильный импорт http  
**Файл:** `api/src/index.ts:36`  
**Решение:** `import * as http from 'http'`

### 5. pnpm-workspace.yaml
**Ошибка:** Не настроены allowBuilds  
**Файл:** `pnpm-workspace.yaml`  
**Решение:** Установить true для всех build пакетов
