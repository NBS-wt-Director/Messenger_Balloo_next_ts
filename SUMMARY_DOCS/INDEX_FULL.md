## 🌐 Веб-сайт документации

Сайт документации доступен по адресу: **http://localhost:3100**

### Команды

```bash
cd SUMMARY_DOCS

# Запуск сайта разработки
npm run dev

# Автообновление из монорепо
npm run update-docs

# Продакшн сборка
npm run build
npm run start
```

### Редактор

Веб-редактор доступен по адресу: **http://localhost:3100/editor**

Доступные для редактирования:
- To_clean.md
- Featurys.md
- Release_plan.md
- Realease_calendare.md
- TZ.md
- Errors.md

```bash
# Поиск по всей документации
grep -r "поисковый запрос" SUMMARY_DOCS/

# Поиск только по контрактам
grep -r "поисковый запрос" SUMMARY_DOCS/Contracts/

# Поиск по имени файла
Get-ChildItem -Path "SUMMARY_DOCS" -Recurse -Filter "*Contract*.md"
```

## ⚠️ ВАЖНО: Работа ИИ с документацией

**Koda (ИИ-ассистент) работает ТОЛЬКО с документами из SUMMARY_DOCS/**

### Правила для ИИ:
1. ✅ Использовать ТОЛЬКО файлы из SUMMARY_DOCS/
2. ❌ НЕ обращаться к docs/, workdocs/, messenger/docs/
3. ✅ Проверять актуальность в INDEX.md
4. ✅ Предлагать обновление SUMMARY_DOCS при изменении кода
5. ✅ Следовать контрактам из Contracts/

### Исключения:
- Чтение кода для анализа
- Чтение package.json для зависимостей
- Чтение конфигов (tsconfig, eslint, prettier)
