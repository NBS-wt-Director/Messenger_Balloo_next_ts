## 📋 ИЗМЕНЕНИЯ ТЗ

### Было:
- Кнопка выбора тем в отдельной секции меню
- Доступна только авторизованным пользователям

### Стало:
- Кнопка выбора тем **рядом с кнопками предустановленных тем**
- Видна **всем пользователям** (авторизованным и неавторизованным)
- Модальное окно доступно всем

---

## 🎯 НОВАЯ СТРУКТУРА UI

### Header Menu (всегда видна)
```
┌─────────────────────────────────────────┐
│  Темы                           [Кнопка]│ ← Кнопка "Все темы"
├─────────────────────────────────────────┤
│ [Светлая] [Тёмная] [Россия] [Все темы] │ ← Кнопки тем в ряд
└─────────────────────────────────────────┘
```

### Модальное окно (доступно всем)
- Неавторизованные: могут просматривать, но при закрытии сброс на светлую тему
- Авторизованные: полная функциональность

---

## 🔌 ЛОГИКА РАБОТЫ

### Неавторизованный пользователь:
1. Открывает модальное окно
2. Смотрит темы
3. Выбирает тему (временно применяется)
4. Закрывает окно → тема сбрасывается на светлую

### Авторизованный пользователь:
1. Открывает модальное окно
2. Смотрит темы
3. Выбирает тему → применяется permanently
4. Для кастомных тем → проверка подписки
