# Docs Content

Platform documentation content in markdown-first format.

## Structure

- `platform-state/` - Platform state documentation
- `designs/` - Design documents
- `contracts/` - Platform contracts (symlink to workdocs/contracts)

## Rules

1. **Markdown-first**: All documentation in markdown
2. **Machine-readable**: JSON/YAML schemas accompany markdown
3. **Version control**: All docs versioned with git
