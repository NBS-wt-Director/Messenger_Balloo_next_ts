## ✅ ИСПРАВЛЕНО СЕГОДНЯ (7 ошибок)

### 1. ROUTES-001: Неверные маршруты сообщений
**Критичность:** Критично  
**Статус:** ✅ Исправлено

**Проблема:**
```javascript
// БЫЛО (неправильно):
messagesRouter.put('/messages/:messageId', ...)
messagesRouter.delete('/messages/:messageId', ...)
// Результат: /api/v1/messages/messages/:messageId (дублирование!)
```

**Решение:**
```javascript
// СТАЛО (правильно):
messagesRouter.put('/:messageId', ...)
messagesRouter.delete('/:messageId', ...)
// Результат: /api/v1/messages/:messageId
```

**Файл:** `api/src/routes/index.js`

---

### 2. API-001: Отсутствовала функция toggleMute
**Критичность:** Высокая  
**Статус:** ✅ Исправлено

**Решение:** Добавлена функция `toggleMute()`
```typescript
export async function toggleMute(chatId: string, muted: boolean, muteUntil?: number | null)
```

**Файл:** `messenger/src/api/chats.ts`

### 3. UI-001: Неправильный вызов API mute
**Критичность:** Высокая
