## ✨ ОСОБЕННОСТИ РЕАЛИЗАЦИИ

### Статусы:
- **Восьмиугольник** - точная геометрия через `clip-path`
- **Яндекс.Диск** - автоматическая загрузка при наличии токена
- **24 часа** - автоматическое удаление через базу данных
- **Views tracking** - сохранение userId в массив views

### Звонки:
- **WebRTC** - чистый peer-to-peer
- **STUN серверы** - Google public STUN
- **Запись** - локальная + загрузка на Яндекс.Диск
- **Сигнализация** - через REST API

### Мобильная адаптация:
- **Breakpoints**: 1024px, 640px, 375px
- **Safe areas**: env(safe-area-inset-*)
- **Touch targets**: минимум 44px
- **Font size**: 16px для предотвращения зума
