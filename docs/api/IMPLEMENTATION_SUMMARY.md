## 🔌 Новые эндпоинты

### Контакты
- `GET /api/v1/contacts/requests` - Получить запросы
- `POST /api/v1/contacts/requests` - Отправить запрос
- `PUT /api/v1/contacts/requests/:requestId` - Обработать запрос

### Синхронизация
- `POST /api/v1/sync/keys` - Синхронизировать ключи
- `GET /api/v1/sync/keys` - Получить ключи

### Админка
- `POST /api/v1/admin/recordings/cleanup` - Очистка записей
- `GET /api/v1/admin/recordings/info` - Информация о записях
- `GET /api/v1/admin/reports` - Список отчётов
- `PUT /api/v1/admin/reports/:reportId` - Обработать отчёт

## ⚡ WebSocket Rate Limiting

**Лимит:** 10 сообщений за 3 секунды

**При превышении:**
```json
{
  "type": "error",
  "error": "Too many messages. Please wait before sending more."
}
```

**Автоматическая очистка:** Каждую минуту

---

## 🗑️ Очистка записей звонков

**Важно:** Очистка выполняется ТОЛЬКО через админку!

**Эндпоинт:**
```bash
POST /api/v1/admin/recordings/cleanup
{
  "days": 30  # Удалить записи старше 30 дней
}
```

**Информация о записях:**
```bash
GET /api/v1/admin/recordings/info
```
