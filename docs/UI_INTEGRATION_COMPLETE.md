## 🔗 API Интеграция

### Загрузка файлов
```typescript
POST /api/yandex-disk/upload
Content-Type: multipart/form-data

{
  file: File,
  messageId: string,
  chatId: string,
  uploaderId: string
}

Response:
{
  success: true,
  attachment: {
    id: string,
    type: 'video' | 'document' | ...,
    url: string,
    fileName: string,
    fileSize: number,
    ...
  }
}
```

### Просмотр видео
```typescript
GET /api/yandex-disk/video/:path
Response: Video stream (MP4)
```

### Скачивание документов
```typescript
GET /api/yandex-disk/download?path=:path
Response: File download with Content-Disposition: attachment
```
