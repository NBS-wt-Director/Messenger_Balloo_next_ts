## 📋 ЧЕК-ЛИСТ ТЕСТИРОВАНИЯ

### 1. Загрузка файлов ⭐⭐⭐⭐⭐ (Критично)

```
1. Откройте чат
2. Нажмите на скрепку (📎)
3. Выберите "Фото"
4. Выберите файл изображения (< 100MB)
5. Проверьте прогресс 0-100%
6. Проверьте что файл появился в чате
7. Нажмите на миниатюру
8. Проверьте открытие модального окна
9. Проверьте кнопку download
```

**Ожидаемый результат:** ✅ Файл загружается, отображается прогресс, открывается просмотр

---

### 2. Пересылка сообщений ⭐⭐⭐⭐⭐ (Критично)

```
1. Откройте чат с сообщениями
2. Кликните правой кнопкой на сообщении
3. Выберите "Переслать"
4. Выберите чат для пересылки
5. Нажмите "Переслать"
6. Проверьте целевой чат
```

**Ожидаемый результат:** ✅ Сообщение появляется в целевом чате с пометкой "Переслано"

---

### 3. Mute чата ⭐⭐⭐⭐ (Важно)

```
1. Откройте чат
2. Нажмите ⋮ (три точки)
3. Выберите "Отключить уведомления"
4. Выберите "На 1 час"
5. Проверьте что меню закрылось
6. Проверьте что появилась иконка 🔕
```

**Ожидаемый результат:** ✅ Уведомления отключены, иконка обновилась

---

### 4. Управление сессиями ⭐⭐⭐⭐ (Важно)

```
1. Откройте /sessions в браузере
2. Проверьте список сессий
3. Проверьте иконки устройств
4. Нажмите "Выйти" на одной сессии
5. Проверьте что сессия исчезла
6. Нажмите "Выйти из всех устройств"
7. Подтвердите действие
```

**Ожидаемый результат:** ✅ Сессии отображаются, завершаются корректно

---

### 5. Ответ на сообщение ⭐⭐⭐ (Средне)

```
1. Откройте чат

3. Нажмите кнопку "Ответить" (если есть)
4. Или выберите сообщение для reply
5. Отправьте ответ
```

**Ожидаемый результат:** ✅ Ответ отображается с цитатой
