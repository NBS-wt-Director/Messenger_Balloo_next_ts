   - Mitigation: Использовать готовые решения (Signal Protocol)

   - Mitigation: Использовать простые peer-to-peer calls

3. **Production deploy** - могут быть проблемы с SSL
   - Mitigation: Иметь rollback plan

   - Mitigation: Code splitting, lazy loading
