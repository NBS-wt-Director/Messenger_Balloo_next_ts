# Design Contract

## Purpose

Этот контракт определяет общие правила дизайна для всех узлов платформы Balloo.

## Rules

### 1. Visual Identity

- **Логотип**: общий для всех узлов, источник в `packages/core-brand`
- **Цветовая палитра**: определяется в `packages/core-theme`
- **Шрифты**: общие для всех узлов
- **Border-radius**: **ЗАПРЕЩЁН** (0px везде) - прямоугольная форма

### 2. Theme System

#### Preset Themes (общие для всех узлов)
- `light` - Светлая тема
- `dark` - Тёмная тема  
- `russia` - Тема с российскими цветами

#### Custom Themes
- **Разрешены только в user-facing приложениях**: web-main, mobile, desktop
- **Запрещены в системных приложениях**: admin, api, infra
- Сохранение тем только после 2 дней использования
- Пользовательские темы без регистрации (доступны всем)

### 3. Components

- Общие UI компоненты в `packages/core-ui`
- Все компоненты должны поддерживать все preset themes
- Компоненты должны быть доступны на всех языках платформы

## Version

- **Contract Version**: 1.0.0
- **Last Updated**: 2026-06-09
- **Status**: Active
