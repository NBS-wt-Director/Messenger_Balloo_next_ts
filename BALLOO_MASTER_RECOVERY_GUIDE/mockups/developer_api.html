Обзор API

Balloo API позволяет интегрировать функционал мессенджера в ваши приложения. API использует REST архитектуру и возвращает данные в формате JSON.

🔐 Аутентификация
  • Все запросы требуют API ключ в заголовке X-API-Key
  • Ключи создаются в личном кабинете разработчика
  • Храните ключи в секрете, не публикуйте в коде
  • Для продакшена используйте OAuth 2.0
Base URL: https://api.balloo.su/v1

Пользователи

GET /users/{user_id}

Получение информации о пользователе по ID

Параметры:

Параметр Тип Описание
user_id string Уникальный ID пользователя

Пример запроса:

curl -X GET "https://api.balloo.su/v1/users/12345" \ -H "X-API-Key: your_api_key_here"

Пример ответа:

{ "id": "12345", "username": "@alexivanov", "email": "alex@balloo.app", "created_at": "2025-01-15T10:30:00Z", "is_premium": true }
POST /users

Создание нового пользователя

Параметры тела:

Параметр Тип Описание
email string Email пользователя (обязательно)
username string Имя пользователя (обязательно)
password string Пароль (обязательно)

Пример запроса:

curl -X POST "https://api.balloo.su/v1/users" \ -H "X-API-Key: your_api_key_here" \ -H "Content-Type: application/json" \ -d '{ "email": "new@user.com", "username": "@newuser", "password": "securepassword123" }'

Сообщения

POST /messages

Отправка сообщения пользователю или в чат

Параметры тела:

Параметр Тип Описание
chat_id string ID чата или пользователя
content string Текст сообщения
type string Тип: text, image, file, voice

Пример:

curl -X POST "https://api.balloo.su/v1/messages" \ -H "X-API-Key: your_api_key_here" \ -H "Content-Type: application/json" \ -d '{ "chat_id": "chat_123", "content": "Привет! Это сообщение через API", "type": "text" }'

Webhooks

Webhooks позволяют получать уведомления о событиях в реальном времени. Настройте endpoint на своём сервере и получайте POST запросы при событиях.

📡 Доступные события
  • message.received — новое сообщение
  • user.online — пользователь онлайн
  • call.started — начался звонок
  • payment.completed — оплата прошла
