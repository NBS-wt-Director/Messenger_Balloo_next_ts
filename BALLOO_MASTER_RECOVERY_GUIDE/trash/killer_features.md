## V1 — Реализуемо в базовом мессенджере

### KF-V1-01: Умный поиск с highlight

**Эффект:** Средний | **Влияние:** Высокое

Поиск по сообщениям, чатам, контактам с подсветкой найденного текста. Автодополнение при вводе. Фильтры: дата, тип вложения, от пользователя.

**Почему V1:** Базовый поиск — must-have для мессенджера. PostgreSQL full-text search + frontend highlight.

---

### KF-V1-02: Self-destruct сообщения с таймером

**Эффект:** Средний | **Влияние:** Высокое

Отправка сообщений, которые автоматически удаляются через 5/10/30/60 секунд или 24 часа. Уведомление при скриншоте (Android). Визуальный таймер на сообщении.

**Почему V1:** Ключевое USP для приватности. TTL в messages table + client-side timer. Простая реализация.

---

### KF-V1-03: Голосовые сообщения с транскрипцией

**Эффект:** Средний | **Влияние:** Высокое

Запись голосовых сообщений до 5 минут. Визуализация волны. Опциональная AI-транскрипция (текст под голосовым). Play с ускорением 1.5x/2x.

**Почему V1:** Голосовые — стандарт мессенджеров. Transcription — через Whisper API (дешёво). Waveform — wavemap library.
