## Разделение V1 и V2

### V1 — Базовая версия (BALLOO_MASTER_RECOVERY_GUIDE/)
- ✅ Авторизация и регистрация
- ✅ Список чатов (главный экран)
- ✅ Приватные и групповые чаты
- ✅ Голосовые и видеозвонки
- ✅ Файлы до 100 МБ
- ✅ E2EE шифрование
- ✅ Настройки, профили, приватность
- ✅ Просмотр вложений (с фильтрами)
- ✅ Поддержка, FAQ, тикеты
- ✅ О Balloo, О компании
- ✅ История версий
- ✅ Поддержать проект

**Кнопки "Балунишка" и "Рынок" на главном экране V1:**
- Неактивные (disabled)
- С пунктирной рамкой
- С подсказкой "🔜 В разработке — функция появится в версии 2.0"

### V2 — Модернизация (V2_ENHANCEMENTS/)
- 🐻 Балунишка Борис (анимированный маскот-помощник)
- 🏪 Рынок (маркетплейс товаров и услуг)
- 🤖 AI-ассистент (чат, генерация, перевод)
- 💰 Кошелёк (покупки, переводы, пополнение)
- 🛡️ Эскроу-сделки (безопасные платежи)
- 📁 Файлы до 1 ГБ
- ⏰ Запланированные сообщения
- 🌐 Автоперевод чатов
- 🏷️ White Label для бизнеса
- 🔌 Developer API и Webhooks

**Кнопки "Балунишка" и "Рынок" на главном экране V2:**
- Активные (ссылки на соответствующие экраны)
- С градиентным фоном
- С описаниями функций

## Миграция V1 → V2

### Для пользователей:
1. Установка обновления до V2
2. Кнопки "Балунишка" и "Рынок" становятся активными
3. Подключение AI-ассистента (требует согласия)
4. Настройка кошелька (по желанию)

### Для разработчиков:
1. Добавление новых таблиц БД (marketplace_items, wallets, transactions, ai_chats)
2. Интеграция платёжного шлюза
3. Подключение AI-модели
4. Настройка White Label конфигурации
