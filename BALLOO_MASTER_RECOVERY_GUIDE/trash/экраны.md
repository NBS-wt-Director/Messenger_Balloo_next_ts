**Дата:** 2026-06-24 | **Версия:** 3.4 | **Статус:** Актуально  
**Автор:** Koda (AI) + NLP-Core-Team  
**Узлов:** 5 (messenger, admin-portal, balloo-landing, premium, store)  

> ⚠️ Документ содержит все пользовательские экраны (страницы + модальные окна + панели) экосистемы Balloo.

# ШАБЛОН ЭКРАНА

| Поле | Описание |
|------|----------|
| **ID** | Уникальный идентификатор экрана |
| **Название** | Человеко-читаемое название |
| **Путь/Локация** | URL-путь или компонент |
| **Узел** | Какой проект/модуль |
| **Описание** | Назначение и функционал |
| **Зависимости** | Общие компоненты, используемые на экране |
| **Связанные экраны** | Навигационные связи |

### COMP-D-001a: OctagonAvatar (Восьмиугольный аватар для видео)

| Поле | Значение |
|------|----------|
| **Название** | Восьмиугольный аватар (видео-контент) |

| **Использует** | `VideoThumbnail` |
| **Используется на** | Видеостатусы, видеосообщения в чате |
| **Props** | `videoSrc?: string`, `thumbnailUrl?: string`, `size?: 'sm'|'md'|'lg'|'xl'`, `status?: 'online'|'offline'`, `isVideo: boolean` |

**Описание:**  
Равносторонний восьмиугольник с видео-превью или thumbnail. Градиентная обводка для активных/онлайн статусов.

**CSS clip-path (равносторонний восьмиугольник):**
```css
clip-path: polygon(30% 0%, 70% 0%, 100% 30%, 100% 70%, 70% 100%, 30% 100%, 0% 70%, 0% 30%);
```
sm (40px):  для списка чатов (видеосообщения)
md (48px):  для chat header
lg (72px):  для ленты статусов
xl (96px):  для профиля / просмотра
```

**CSS clip-path для равностороннего шестиугольника:**
```css
clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%);
```
