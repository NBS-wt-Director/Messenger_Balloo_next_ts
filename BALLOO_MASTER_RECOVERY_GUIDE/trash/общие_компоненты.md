### COMP-L-001: Header (Шапка)

| Поле | Значение |
|------|----------|
| **Название** | Глобальная шапка |
| **Тип** | `layout` |
| **Уровень** | `organism` |
| **Использует** | `Avatar`, `SearchBar`, `Badge`, `DropdownMenu`, `NotificationBell` |
| **Используется на** | `SCR-M-005` (чаты), `SCR-M-006` (чат), `SCR-A-002` (дашборд), `SCR-A-003` (пользователи) |
| **Props** | `user?: User`, `onSearch?: (q: string) => void`, `onNotifications?: () => void`, `onMenu?: () => void` |

**Описание:**  
Верхняя панель приложения. Содержит: логотип Balloo (слева), поиск (центр), уведомления с badge (право), аватар пользователя с dropdown-меню (правый край). На странице чата — информация о чате вместо поиска.

**Размеры — Desktop:**
```
┌──────────────────────────────────────────────────────┐  ← 64px height
│  🎈 Balloo    [ 🔍 Поиск... ]    🔔(3)  👤 ▼        │
└──────────────────────────────────────────────────────┘

Логотип: 32×32px, left 16px
Поиск:   320px wide, 32px height, 12px padding
Badge:   16×16px circle, font 11px, top-right offset -4px
Avatar:  32×32px circle, right 16px
Dropdown: 200px wide, 36px items, 8px padding
```

**Размеры — Mobile:**
```
┌──────────────────────────┐  ← 56px height
│ 🎈 Balloo     🔍 +       │
└──────────────────────────┘

Логотип: 24×24dp, left 12dp
Поиск:  28dp icon, right 8dp
Кнопка: 24×24dp, right 4dp
```

**Позиционирование:**
```
Desktop (1440px):
  left:  16px (logo) → 16px
  right: 16px (avatar) → right edge
  search: center, 320px width

Desktop (1920px):
  left:  24px (logo) → 24px
  right: 24px (avatar) → right edge
  search: center, 400px width

Mobile:
  full width, no padding sides
  content centered vertically (56px height)
```

**Поведение:**
- Поиск: debounce 300ms, автоподсказки
- Уведомления: badge показывает непрочитанные, клик → dropdown со списком
- Аватар: клик → dropdown меню (Профиль, Настройки, Выйти)
- Responsive: на mobile — burger menu, поиск в отдельном drawer

### COMP-D-001: Avatar (Аватар)

| Поле | Значение |
|------|----------|
| **Название** | Аватар пользователя |
| **Тип** | `data-display` |
| **Уровень** | `atom` |
| **Использует** | Нет |
| **Используется на** | Практически все экраны |
| **Props** | `user?: User`, `size?: 'sm'|'md'|'lg'|'xl'|'xxl'`, `status?: 'online'|'offline'|'away'`, `onClick?: () => void` |

**Описание:**  
Равносторонний восьмиугольник (regular octagon) для всех типов контента: текст, фото, видео. Градиентная обводка (blue→purple) для активных/онлайн статусов. При отсутствии фото — первая буква имени с градиентным фоном.

**CSS clip-path (равносторонний восьмиугольник):**
```css
clip-path: polygon(30% 0%, 70% 0%, 100% 30%, 100% 70%, 70% 100%, 30% 100%, 0% 70%, 0% 30%);
```

**Размеры — Desktop:**
```
sm (24px):  [A]  — badge, inline
md (32px):  [ A ]  — header, compact lists
lg (40px):  [  A  ]  — chat list cards
xl (72px):  [    A    ]  — status bar, groups
xxl (120px): [       A       ]  — profile page
```

**Размеры — Mobile:**
```
sm (24dp):  [A]  — badge, inline
md (36dp):  [ A ]  — header
lg (48dp):  [  A  ]  — chat list cards
xl (72dp):  [    A    ]  — status bar, groups
xxl (96dp): [       A       ]  — profile page
```

**Статус-индикатор (точка):**
```
[ A ] ●  (online — зелёная точка 8px, bottom-right, offset -4px, border 2px)
[ A ] ○  (offline — серая точка 8px)
[ A ] ⚠  (away — жёлтая точка 8px)
```

**Позиционирование статус-индикатора:**
```
Desktop (lg 40px):
  top-right offset: -4px, -4px
  dot size: 8×8px
  border: 2px white

Mobile (lg 48dp):

  dot size: 10×10dp
  border: 2dp white
```

## HEXAGON — РАСЧЁТ РАЗМЕРОВ (УДАЛЕНО — теперь OCTAGON)

> ⚠️ **Устарело:** ранее использовался шестиугольник для видео. Теперь все аватары — равносторонний восьмиугольник.

**Ранее использовалось:**
```
Для равностороннего шестиугольника (regular hexagon):

Ширина = W
Высота = W × 1.1547 (cos(30°) × 2)

sm: 40px × 46px (40 × 1.1547 = 46.188)
md: 48px × 55px (48 × 1.1547 = 55.426)
lg: 72px × 83px (72 × 1.1547 = 83.138)
xl: 96px × 111px (96 × 1.1547 = 110.851)
```

**Теперь используется OCTAGON:**
```css
clip-path: polygon(30% 0%, 70% 0%, 100% 30%, 100% 70%, 70% 100%, 30% 100%, 0% 70%, 0% 30%);
```

**Размеры octagon (квадратные, width = height):**
```
sm: 24×24px    (badge, inline)
md: 32×32px    (header, compact lists)
lg: 40×40px    (chat list cards)
xl: 72×72px    (status bar, groups)
xxl: 120×120px (profile page)
```
