# 👤 Пользовательский Анализ

**Дата создания:** 26.06.2026  
**Последнее обновление:** 2026-06-26  
**Платформа:** Balloo Platform  

---

## Сильные стороны (для пользователя)

### US-01: E2E шифрование ⭐ Высокое влияние

Сообщения видит только отправитель и получатель. Даже разработчики не могут прочитать. Это ключевое конкурентное преимущество перед WhatsApp (MTProto не true E2E по умолчанию) и Telegram (E2E только в Secret Chats).

**Польза:** Полная приватность. Не нужно бояться утечек.

---

### US-02: 11 языков, включая малые народы ⭐ Высокое влияние

Татарский, башкирский, якутский, чеченский, удмуртский, чувашский, осетинский. Ни один конкурент (WhatsApp, TG, Viber) не поддерживает такой набор языков для РФ/СНГ.

**Польза:** Носители малых языков могут общаться на родном языке. Инклюзивность.

---

### US-03: Self-destruct сообщения Среднее влияние

Автоматическое удаление через настраиваемый таймер. Удобно для чувствительной информации (пароли, номера карт, личные секреты).

**Польза:** Не нужно вручную удалять сообщения. Безопасность по умолчанию.

---

### US-04: Мультиаккаунт Среднее влияние

Несколько аккаунтов в одном приложении. Переключение в 1 клик. Удобно для разделения личного и рабочего.

**Польза:** Не нужно устанавливать 2+ приложения. Всё в одном месте.

---

### US-05: 3 темы + кастомизация Низкое влияние

Тёмная, светлая, 'Russia'. Настройка цветов. Пользователи ценят кастомизацию — это emotional connection к приложению.

**Польза:** Приложение выглядит уникально. Не 'как у всех'.

---

### US-06: Всё бесплатно в V1 ⭐ Высокое влияние

Нет платных ограничений в базовой версии. Нет рекламы. Нет paywall за функции, которые конкуренты делают платными (стикеры, темы).

**Польза:** Полноценный мессенджер без оплаты. Не нужно бояться 'внезапной' монетизации.

---

### US-07: Голосовые + видео сообщения Среднее влияние

Отправка голосовых и видео. Визуализация waveform. Play с ускорением. Удобнее текста для некоторых людей.

**Польза:** Быстрее говорить, чем печатать. Эмоции передаются лучше.

---

### US-08: Стикеры и реакции Среднее влияние

Пакеты стикеров, эмодзи-реакции. Эмоциональное выражение без текста. Social bonding.

**Польза:** Выражать эмоции веселее, чем текстом. Стикеры = social currency.

## Слабые стороны (для пользователя)

### UW-01: Высокий порог входа ⭐ Высокое влияние

Email → код → displayName → 2FA → E2E key generation. 5+ шагов. Telegram: телефон → готово. WhatsApp: телефон → готово. Balloo: дольше и сложнее.

**Трение:** Пользователь уйдёт на 2-й шаге. 40% отток на регистрации в мессенджерах.

---

### UW-02: Нет контакта-бейза 🔴 Критическое влияние

WhatsApp/TG работают потому, что ВСЕ контакы там. Balloo — пустой. Пользователь не видит ценности, потому что не с кем общаться. Network effect problem.

**Трение:** «Зачем мне этот мессенджер, если тут нет моих друзей?»

---

### UW-03: E2E = потеря ключей = потеря сообщений ⭐ Высокое влияние

Если пользователь сменил устройство и не восстановил E2E ключи — все прошлые сообщения потеряны. Нет cloud backup для E2E. Это пугает не-технических пользователей.

**Трение:** «Я сменил телефон и потерял все переписки!»

---

### UW-04: Нет familiar brand recognition ⭐ Высокое влияние

Никто не знает Balloo. WhatsApp, TG, Viber — бренды, которым доверяют. Новый бренд = недоверие. Особенно для финансовых операций (кошелёк V2).

**Трение:** «Это не мошенничество? Почему я должен ему доверять?»

---

### UW-05: Сложная навигация Среднее влияние

Три навигационных паттерна сбивают с толку. Новый пользователь не понимает, где что. Telegram интуитивен: чат → сообщения. Balloo: sidebar → chatlist → messages → ???

**Трение:** Первые 5 минут = confusion. Если не разобрался за 5 минут — ушёл.

---

### UW-06: Offline mode не описан Среднее влияние

Что если интернет пропал? Можно ли читать сообщения? Отправлять? Balloo не объясняет это пользователю. Ожидание = disappointment.

**Трение:** «Я offline и не могу прочитать последние сообщения. Приложение сломано?»

---

### UW-07: Нет familiar onboarding Среднее влияние

Нет пошагового туториала. Нет «как начать общаться». Пользователь открывается в пустой чат-лист и не понимает, что делать.

**Трение:** Blank slate problem. Нужен onboarding: «Нажмите + чтобы создать чат».

---

### UW-08: Маскот 🐻 может раздражать Низкое влияние

Анимированный маскот — мило для одних, раздражает других. Не все хотят «игрушку» в мессенджере для работы.

**Трение:** «Отключите эту анимацию, мне нужно работать».

---

### UW-09: Нет cross-platform awareness Среднее влияние

Desktop и Mobile версии не синхронизированы в описании. Пользователь может не знать, что может использовать на разных устройствах.

**Трение:** «А можно с телефона и компьютера одновременно?»

---

### UW-10: Support quality неизвестна Среднее влияние

Новый мессенджер с проблемами поддержки = потерянные данные. Пользователи боятся потерять переписки при багах.

**Трение:** «Если что-то сломается, кто мне поможет?»

---

## Рекомендации

1. **Упростить onboarding** до 2-3 шагов максимум
2. **Добавить cloud backup E2E ключей** для снижения риска потери сообщений
3. **Создать onboarding-туториал** с пошаговым объяснением
4. **Включить cross-platform awareness** в описание платформы
5. **Добавить возможность отключения маскота** для пользователей, предпочитающих минимализм
