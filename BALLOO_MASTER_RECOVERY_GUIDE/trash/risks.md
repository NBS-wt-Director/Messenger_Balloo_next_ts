# ⚠️ Матрица Рисков

**Дата создания:** 26.06.2026  
**Последнее обновление:** 2026-06-26  
**Платформа:** Balloo Platform  

---

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Потеря E2E ключей при смене устройства | Высокая | Критическое | Cloud backup ключей (зашифрованный) или Signal Protocol |
| XSS → утечка E2E ключей | Средняя | Критическое | CSP headers, PIN-шифрование ключей, Content-Security-Policy |
| Yandex Disk блокировка | Средняя | Критическое | Storage Abstraction Layer + S3-compatible (MinIO, R2) |
| Нехватка ресурсов для V2 | Высокая | Высокое | Запустить V1, валидировать, потом V2. Приоритизация фич. |
| Низкий retention (D30 < 10%) | Средняя | Высокое | Push, stories, группы — ключевые retention-фичи. A/B тестирование onboarding. |
| DDoS / abuse платформы | Средняя | Высокое | Rate limiting, Cloudflare WAF, модерация контента, капча |
| Утечка персональных данных | Низкая | Критическое | Шифрование БД, access controls, audit logs, регулярные pentest |

---

## Рекомендации по управлению рисками

1. **Приоритет 1:** Cloud backup E2E ключей — критический риск для пользовательского доверия
2. **Приоритет 2:** Multi-storage abstraction — зависимость от Yandex Disk недопустима
3. **Приоритет 3:** CSP headers — XSS защита критична для E2E безопасности
4. **Приоритет 4:** A/B тестирование onboarding — retention ключ к успеху
