## 3. ТЕМЫ ОФОРМЛЕНИЯ

### 3.1 Пресеты тем

В системе ровно **3 пресета** (single source of truth):

| ID | Название | Описание |
|----|----------|----------|
| `dark` | Тёмная | По умолчанию. Фон #0F172A, текст светлый |
| `light` | Светлая | Фон #FFFFFF, текст тёмный |
| `russia` | Россия | Градиентный фон флага РФ, металлик-карточки |

**Важно:** Тем по умолчанию — **ровно 3**. Никаких дополнительных тем (синих, океанских, лесных и т.д.) **не существует**. Все упоминания "синей темы" — отсебятина, которую нужно удалить из документации и кода.

### 3.2 Пользовательские темы

Пользователи могут создавать собственные темы через CSS-переменные:

```typescript
interface CustomTheme {
  id: string;
  name: string;
  colors: ThemeColors;
  isFavorite: boolean;
  createdAt: number;
  updatedAt?: number;
  createdBy?: string;
}
```

**Ограничения:**
- Подписка на тему: автообновление при изменении автором
- Хранение: localStorage + серверная синхронизация
- Лимит бесплатных тем: 10
- Premium: неограниченно + эксклюзивные

### 3.3 Переключение тем

```typescript
type ThemePresetId = 'dark' | 'light' | 'russia';

// Zustand store: theme-store.ts
setTheme(theme: ThemePresetId);
toggleTheme(); // Циклическое переключение: dark → light → russia → dark
```

**Механизм:**
- CSS-атрибут `data-theme="dark|light|russia"` на `<html>`
- CSS-переменные обновляются автоматически
- Сохранение в localStorage + серверная синхронизация

## 6. ДИЗАЙН-КОНТРАКТ (DesignContract)

> ⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО:** Все компоненты **ОБЯЗАНЫ** соблюдать DesignContract.

### 6.1 Border Radius = 0

```typescript
// packages/core-ui/src/design-tokens.ts
export const BORDER_RADIUS = {
  none: '0',
  sm: '0',   // Enforced: no rounding
  md: '0',   // Enforced: no rounding
  lg: '0',   // Enforced: no rounding
  xl: '0',   // Enforced: no rounding
  full: '0', // Enforced: no rounding
} as const;
```

**Правила:**
- ✅ **НИ ОДНОМ** компоненте не может быть скруглённых углов
- ✅ Все карточки, кнопки, модальные окна, инпуты — **остроугольные**
- ✅ Это архитектурное решение, а не упущение
- ✅ Нарушение = **критический баг**

### 6.2 Обоснование

1. **Современный эстетический стиль** — sharp, brutalist-минимализм
2. **Единство платформы** — все узлы выглядят как единая система
3. **Производительность** — отсутствие CSS `border-radius` упрощает рендеринг
4. **Доступность** — чёткие границы лучше воспринимаются скринридерами

### 6.3 Проверка

```typescript
// packages/core-ui/src/types.ts
export interface DesignContractCompliant {
  /** Must be 0 - no rounded corners allowed */
  borderRadius: '0';
}
```

## 13. СТАТУС-СОСТОЯНИЯ И ОБРАТНАЯ СВЯЗЬ

### 13.1 Статусы сообщений

```
sent:    ✓  (одна галочка, серая)
delivered: ✓✓ (две галочки, серые)
read:    ✓✓ (две галочки, синие #3b82f6)
```

### 13.2 Состояния загрузки

```
Кнопка: loading={true} → текст "Загрузка..." + спиннинг ⟳
Файл: progress bar 0-100%
Сообщение: optimistic update → статус обновляется через WebSocket
```

### 13.3 Валидация форм

```
Пароль: 6-9 символов (числа / строчные английские / заглавные английские / строчные русские / заглавные русские / ! / @ / _)
Код SMS: ровно 3 цифры
Email: стандартная валидация код = ровно 3 цифры
Телефон: +7XXXXXXXXXX
```

### 13.4 Toast-уведомления

```
Позиция: top-4 right-4
Длительность: 3 сек (по умолчанию)
Автозакрытие с прогресс-баром
Анимация: slideIn (вход), translateX(100%) (выход)
```

### 13.5 Ошибки

```
Форма: красный блок auth-error над полем
Alert: красная полоса слева (border-left: 4px solid #ef4444)
Toast: красная иконка AlertCircle
```
